Phosphor Regular (MIT, `@phosphor-icons/core` 2.1.1) with four Fill weights for active and alert state: `record-fill`, `microphone-fill`, `camera-fill`, `bell-simple-fill`. Single-ink SVGs drawn in `fg-muted` (`#8a8a8a`). `<img>` cannot inherit color, so inline the path data when a state needs another ink: `alert` for live mic, camera and recording, critical battery and network down.

Use at 16px (`icon`) in the bar and search field. Network and Bluetooth are icon only. Muted volume uses `speaker-slash`, DND uses `bell-slash`, a live recording uses `record-fill`.
