# Design documents

The documents this desktop was designed from, kept for reference.

- `spec/hyprland-design-spec.md`: the original design spec (layout, keybinds, idle chain,
  workspace rules).
- `spec/hyprland-island-state-spec.md`: how the island at the top of the bar behaves.
- `design-system/`: the visual reference (tokens, geometry, icons).

The desktop has moved on since they were written, so where they disagree with the configs, the
configs are right. Gaps are 6px instead of 4, colours come from the wallpaper, and the tooling
named in the design system (Waybar, Mako, hyprlock) was replaced by Quickshell. Since October
2026 the bar is a rounded frame with coloured chips, the panels grow out of it, and sound,
network, Bluetooth, battery and power are one quick-settings panel.
